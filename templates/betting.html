How to read these results

A favorite is the fighter with the higher implied probability from the two American moneylines: −a uses a/(a+100), +a uses 100/(a+100). Equal implied probabilities are tied prices. An upset is an eligible underdog win. Rates use decisive bouts with two valid, unequal prices; draws and no contests are excluded. Every favorite loss is an underdog win.

Odds include bookmaker margin. No margin removal, return simulation or predictive model is used. Missing bouts, historical result revisions and name differences can affect coverage. These records supplement the existing fight history, which may have a different source cutoff.
